# Built-in aerial wallpaper collection

The build workflow fetches twelve 16:9 photographs from Unsplash at 1600×900 for use as an offline launcher wallpaper pack. Each image is distributed under the Unsplash License as shown on its source page. If an image cannot be downloaded during a build, the launcher uses a procedural local fallback for that slot.
